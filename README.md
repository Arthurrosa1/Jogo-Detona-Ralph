
## 🎮 Jogo Detona Ralph</h1>

Jogo divertido inspirado no filme *Wreck-It Ralph* (Detona Ralph), desenvolvido para praticar e treinar habilidades com **HTML**, **CSS** e **JavaScript**.  
O objetivo é clicar no Ralph sempre que ele aparecer na tela para ganhar pontos!

---

## 🧠 Sobre o Projeto

Este projeto foi criado com o intuito de reforçar conhecimentos sobre:

- Manipulação do DOM com JavaScript  
- Eventos e interações com o usuário  
- Contagem de tempo e pontuação  
- Estruturação de um jogo simples com HTML5 e CSS3  

---

## 🛠️ Tecnologias Utilizadas

| Tecnologia | Finalidade |
|-------------|-------------|
| 🟦 **HTML5** | Estrutura básica do jogo |
| 🎨 **CSS3** | Estilo, layout e design da interface |
| 🟨 **JavaScript** | Lógica, movimentação e pontuação |
